# Painel de Normativos do DOU

Painel diário em HTML autocontido com normativos do Diário Oficial da União (DOU) curados por tema: governo digital, inteligência artificial, processos administrativos, pesquisa acadêmica e administração pública.

Gerado com o apoio do Claude (Anthropic), com curadoria de [Darci de Borba](https://www.darcideborba.com.br).

## Visualizar

Abra `index.html`, ou acesse via GitHub Pages (quando habilitado) em:

`https://darcideborba.github.io/painel-normativos-dou/`
